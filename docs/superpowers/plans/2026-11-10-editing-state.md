# zsh 编辑状态内存基础实施计划

> 使用 executing-plans 和 test-driven-development；本计划只实现 T09 可独立验证的会话状态基础，不实现 zsh 采集、IPC 或生产接入。

**目标：** 以有界内存保存最近一次可靠的编辑快照，并在执行、取消或断连后清除。
**架构：** 调用方提供单调递增版本、有效 UTF-8 输入及 UTF-8 字节边界光标；状态容器不读取终端、磁盘或时钟，不记录日志。不负责认证来源或判断焦点。
**技术：** Go 1.27.3 标准库，无新增依赖。
**设计依据：** `docs/design.md` 第 4、8、9 节；总计划 T09。

## 约束与审查重点

- 无持久化或日志；输入和消息只驻留内存，清除不能保证 Go 运行时擦除历史内存。
- 会话隔离由每个容器实例和调用方保证，容器不是身份凭据。
- 输入最多 64 KiB；空行合法；拒绝无效 UTF-8、非字符边界光标和非法版本。
- 过期快照不能覆盖较新快照；结束后旧版本不能恢复。无效的新版本必须使旧快照失效并推进版本，过期更新不能改变当前状态。
- 按互斥锁保证并发读取与更新；不代表跨 IPC 或 shell 编辑的原子性。

## 任务：会话关闭时无条件失效

**边界：** 独立内存容器新增幂等、不可逆的关闭操作；关闭后无论最后版本如何都丢弃快照，拒绝任何更新或清除版本，不能由迟到消息重开；调用方须在断连时调用，尚不接生产。普通执行或取消仍使用版本化 `Clear`。不保证擦除 Go 历史内存或撤销已经返回的副本。

- [x] 先测试最大版本后关闭、重复关闭、迟到更新与并发更新；确认缺少关闭接口而失败。
- [x] 实现互斥保护的关闭与失败关闭；2026-11-10 定向、race、全量和离线测试通过；总计划 T09 保持未勾选。

## 任务：有界编辑快照

**文件：** `internal/editstate/state.go`、`internal/editstate/state_test.go`。
**接口：** `State.Update(version uint64, line string, cursor int) error`、`State.Clear(version uint64) error`、`State.Snapshot() (Snapshot, bool)`；`Snapshot` 包含 `Version uint64`、`Line string` 和 `Cursor int`。所有版本必须大于此前接受的版本且非零；`Clear` 亦推进版本。

- [x] 编写快照、移动、清除与旧版本拒绝测试，验证过期输入不修改当前状态及清除后不重现旧输入；另先复现无效的新版本遗留旧快照，再实现失败关闭并推进版本。
- [x] 运行 `go test ./internal/editstate -count=1`，确认接口缺失导致失败。
- [x] 实现同步状态容器并验证 UTF-8、边界和 64 KiB 大小；不连接生产。
- [x] 覆盖并发访问、实例隔离、空行和大小边界，运行定向、全量、离线和 race 测试；总计划 T09 保持未勾选。首次实现后测试使用的 `git café` 光标 8 位于 UTF-8 字符中间，修正为字节偏移 9 后通过。
- [x] 2026-11-10：短编辑输入为 4 MiB 字符串的切片时，回归测试先复现状态保留整个底层字符串；保存时复制有效输入后，编辑状态定向、race、全量及离线测试通过。清除仍不保证擦除内存，调用方也可继续持有原输入；不改变 T09 生产接入状态。
