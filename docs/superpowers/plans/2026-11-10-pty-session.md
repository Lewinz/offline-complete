# 离线终端会话实施子计划

> 本计划细化总计划的 T05–T07；执行时沿用 `docs/design.md` 和总计划的离线及安全约束。尚未完成的条目不能视为验收通过。实现语言为 Go。

**目标：** 显式启动本地 shell，并最终提供不会破坏调用方终端状态的交互式 PTY 代理。

**选型：** 使用 Go 1.27.3 与固定版本 `github.com/creack/pty` v1.1.24，依赖 vendor 到 `vendor/`，构建使用 `-mod=vendor`，不抽取与 Amazon Q 会话、IPC 和云端功能耦合的 `figterm` 主循环。该模块声明 MIT，目标平台上只使用 Go 标准库；许可证见 `third_party/creack-pty/`。`go list -m all` 与 `go mod verify` 可复查模块，但都不是运行时联网证明。

**模块边界：** `internal/session.Spawn(program, args...)` 启动指定程序并持有 PTY 与直接子进程；`Reader` 提供输出端，`Writer` 提供输入端，`Resize` 更新字符尺寸，`Wait` 缓存退出状态，`Terminate` 终止进程组并回收，`Close` 幂等关闭。`cmd/offline-complete` 是显式命令行代理。目前没有自动修改 shell 配置、交互式代理或后台服务。

**已实现（2026-11-10）：**

- 显式程序与参数、80×24 初始尺寸、输入输出、退出码、EOF、resize、启动失败和进程组终止。
- 关闭 writer 不再注入任何字节；PTY 无法独立半关闭输入，因此调用方 stdin EOF 不会自动变成子进程 EOF。显式输入终端 EOF 字符仍可传递。
- 终止时先向初始进程组发送 `SIGHUP`，宽限 500ms 后必要时发送 `SIGKILL`；并发 `Wait` 不再阻塞终止。脱离进程组的后代仍无法保证回收。
- 命令行代理转发 stdin/stdout，返回子进程退出码；参数缺失、启动失败及输入输出错误返回非零并输出错误。
- macOS 终端模式在调用期间切为原始模式并在返回时恢复；继承有效的初始尺寸并同步 SIGWINCH。正常退出、输出错误和尺寸有伪终端测试。
- macOS 终端输入使用可停止的 kqueue 读取，代理退出前等待其结束；SIGTERM/SIGHUP 有独立进程与伪终端恢复测试。Unicode、方向键、括号粘贴序列及 Ctrl-C 有伪终端透传测试。

**已知限制：**

- 直接子进程退出后不再追踪或保证回收后代；后代自行 `setsid` 或脱离进程组也可能存活。进程组信号失败时尝试直接强杀，直接强杀失败仍无法保证回收；并发退出时的进程组 ID 重用风险仍需处理。
- 当前 stdin 结束不会自动向子进程传递 EOF，等待输入的程序可能继续等待；待设计不提交未完成输入的安全处理。
- 可捕获的 SIGTERM、SIGHUP、SIGINT 无论 stdin 是否为终端均进入清理路径；SIGKILL、崩溃或突然断电无法保证恢复。macOS 终端、管道及 socket 文件输入要求代理独占读取；其他阻塞 Reader 仍可能在退出后继续读取。SIGWINCH 在初始尺寸读取前注册，尺寸读取或更新失败会结束代理并报告错误；首次读取与子进程启动之间的竞态有伪终端测试。
- Unicode、方向键、括号粘贴和 Ctrl-C 已通过伪终端测试；iTerm2 和 macOS Terminal 真机测试仍待人工执行。
- PTY 输出 EOF 因平台而异；被信号终止时退出码为 `128 + 信号编号`，`ExitStatus` 没有单独的信号字段，无法仅凭退出码区分正常退出。
- 非零退出是状态而不是错误；只有等待失败才返回 error。`Close` 返回终止或 PTY 关闭错误。
- 第一版只支持 macOS/Unix；Windows 路径未实现。
